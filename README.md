# DefiEmber

Simulates real-time cryptocurrency exchange rates and liquidity pool data for decentralized finance (DeFi) users.

The key benefits of using DefiEmber include:

- Simulates real-time cryptocurrency exchange rates
- and liquidity pool data for
- decentralized finance (DeFi) users

## Technology Stack

- rust

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiEmber.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure DefiEmber, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
